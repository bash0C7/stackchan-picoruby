# API reference

Generated by `rake docs` from the `#:` signatures and comments in the source.

## mrbgems

- [picoruby-aw88298](../../mrbgems/picoruby-aw88298/README.md) — AW88298 class-D amplifier over I2C (0x36) with mu-law playback over I2S.
- [picoruby-drb-ble](../../mrbgems/picoruby-drb-ble/README.md) — dRuby transport over BLE: carries a DRb TCP stream in 180-byte chunks over a write/notify characteristic pair.
- [picoruby-si12t](../../mrbgems/picoruby-si12t/README.md) — Si12T 3-zone capacitive touch sensor (I2C 0x68).
- [picoruby-stackchan-controller](../../mrbgems/picoruby-stackchan-controller/README.md) — Controller engine for StackChan: a `StackChan.controller` DSL, a BLE central that talks to the robot over dRuby, a link state machine, and the daemon and CLI that run the declared actions.
- [picoruby-stackchan-led](../../mrbgems/picoruby-stackchan-led/README.md) — 12-pixel WS2812 ring on the StackChan CoreS3, driven through the PY32 I/O expander.
- [picoruby-stackchan-protocol](../../mrbgems/picoruby-stackchan-protocol/README.md) — Frame encoding and parsing for the StackChan BLE command protocol (`<key:value,...>` frames).
- [picoruby-stackchan-robot](../../mrbgems/picoruby-stackchan-robot/README.md) — Robot engine of the StackChan CoreS3 firmware: a DSL for faces, touch reactions and periodic work, the cold-boot sequence, and the BLE peripheral that serves dRuby.
