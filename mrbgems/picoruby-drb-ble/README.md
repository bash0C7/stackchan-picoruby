# picoruby-drb-ble

dRuby transport over BLE: carries a DRb TCP stream in 180-byte chunks over a write/notify characteristic pair.

## Usage

```ruby
require 'drb-ble'

DRbBle.register("drbble://robot", link, timeout_ms: 3000)
front = DRb::DRbObject.new_with_uri("drbble://robot")

responder = DRbBle::Responder.new(front_object, allow: [:command, :touches])
reply_bytes = responder.feed(request_bytes)
```

`link` responds to `send_chunk(bytes)` and `poll` (the next received bytes, or nil).
URIs that start with `drbble://` use the registered link; other URIs use the original `DRb.create_socket`.
A read that gets no data within `timeout_ms` raises `DRb::DRbConnError`.
`Responder#feed` returns the replies for the complete requests it holds; methods outside `allow` get a `NoMethodError` reply, and requests above `MAX_REQUEST` (4096 bytes) are dropped.
