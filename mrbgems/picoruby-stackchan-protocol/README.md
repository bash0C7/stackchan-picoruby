# picoruby-stackchan-protocol

Frame encoding and parsing for the StackChan BLE command protocol (`<key:value,...>` frames).

## Usage

```ruby
require 'stackchan-protocol'

frame = Stackchan::BLE::FrameCodec.encode_head(yaw_left: 50, yaw_right: nil, pitch_up: 30, time_ms: 500, velocity: nil)
Stackchan::BLE::FrameCodec.encode_face(face_name: :joy)
Stackchan::BLE::FrameCodec.parse_touch("<touch:1>")

parser = StackchanProtocol::FrameParser.new
parser.feed("<YL:50,T:500>")
Stackchan::AI::FrameText.build(face_index: 2, text: "hello")
```

`FrameCodec` encodes face, LED, head, torque, self-test and position-read commands; face names are `neutral`, `smile`, `joy`, `surprised`, `sad` and `angry`.
Head frames take `yaw_left` or `yaw_right` (not both), `pitch_up`, and `time_ms` or `velocity`.
`FrameParser#feed` returns a Hash per complete frame; `FrameText.build` sanitizes the text and limits it to `MAX_CHARS` characters.

### `StackchanProtocol::FrameParser`

Splits a byte stream into "<key:value,...>" frames and decodes each into a Hash.
Keeps the last MAX_BUFFER characters of unparsed input.

Source: `mrbgems/picoruby-stackchan-protocol/mrblib/stackchan-protocol/frame_parser.rb`
